# Clearpath — Customs Operations

A React + TypeScript starter UI for managing customs order milestones and operational workflows.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
```

This is a frontend prototype with sample data. Orders created in the UI are held in browser memory and are not persisted to a backend.
